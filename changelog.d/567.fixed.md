When a bucket id taken from the local cache is no longer known to the server (the bucket was deleted, or deleted and recreated, from elsewhere), print the same hint as for an unknown bucket name, `run b2 bucket list to reset cache`, instead of a bare `Bucket with id=... not found` error. The hint now also reaches commands such as `ls` that wrap errors in a `CommandError`. The underlying stale-cache bug is fixed in b2sdk.
